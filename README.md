# LearnLens AI

AI-driven prompt evaluation system for personalized educational recommendations using LLMs, adaptive prompting, and educational quality analysis.

---

# Overview

LearnLens AI is a notebook-based AI experimentation project focused on understanding how different prompt-engineering strategies affect the quality of personalized educational recommendations generated by large language models.

The project simulates a lightweight adaptive learning workflow where student performance data is analyzed to generate:

* learning-gap analysis
* topic prioritization
* practice recommendations
* motivational guidance

using multiple prompting approaches.

Instead of only generating AI responses, the project emphasizes:

* structured LLM evaluation
* recommendation quality analysis
* pedagogical effectiveness
* product-oriented AI experimentation

---

# Objectives

* Explore how prompt structure impacts educational recommendation quality
* Compare generic vs structured adaptive-learning prompts
* Build an evaluation framework for AI-generated outputs
* Analyze tradeoffs between prompt complexity, latency, and recommendation quality
* Simulate real-world educational AI experimentation workflows

# Prompt Strategies

The project evaluates three prompting approaches:

## V1 — Generic Prompt

Basic recommendation generation with minimal structure.

## V2 — Structured Tutoring Prompt

Educationally guided prompt requesting:

* conceptual gap analysis
* practice sequencing
* difficulty progression
* motivational support

## V3 — Adaptive Learning Prompt

Advanced prompt optimized for:

* personalization
* pedagogical sequencing
* engagement consistency
* cognitive load balancing

---

# Evaluation Metrics

Each AI-generated recommendation is evaluated using a structured scoring framework across:

| Metric               | Description                        |
| -------------------- | ---------------------------------- |
| Personalization      | Relevance to student profile       |
| Clarity              | Readability and structure          |
| Pedagogical Quality  | Educational effectiveness          |
| Actionability        | Practical next steps               |
| Engagement Potential | Motivation and consistency support |

# Key Insights

The experimentation revealed that:

* structured prompts significantly improve recommendation quality
* educational AI systems require evaluation-driven workflows
* personalization improves student engagement potential
* prompt complexity introduces tradeoffs in latency and scalability
* AI outputs should be measured systematically rather than accepted blindly
